# 장대양봉 중심값 규칙 1차 탐색 설계 (사전 고정, 2026-10-12)

결과를 보기 **전에** 정한 규칙이다. 이 문서대로만 실행하고, 결과를 보고 규칙·기준을 바꾸지 않는다.
바꿀 이유가 생기면 날짜와 이유를 남기고 "2차"로 새로 시작한다.

## 출처·가설
- 인스타 bullish_bee 「가짜 돌파 피하는 법: 장대양봉의 중심값」(2026-10-12 확인). 근거는 샌디스크 장대양봉 6번뿐.
- 주장 ①: 신고가 장대양봉 뒤 **종가가 몸통 중심값((시가+종가)/2) 위**면 이어서 오르고, 아래면 쉬어 간다.
- 주장 ②: 진입 후 "종가가 중심값 아래면 손절"하면 손절은 짧고 익절은 길어진다.

## 데이터
- `daily_ohlcv`(수정주가, 6자리 코드만), 보통주(`stock_master` is_etf=0, KOSPI·KOSDAQ, 끝자리 0, 스팩 제외 — `swing_combo_explore.py`와 같음).

## 신호(D일 장 마감 후 확정)
1. 대상: D일 거래대금 상위 300, D 종가 ≥ 1,000원.
2. 신고가: D 종가 > 직전 250거래일(D−250 ~ D−1) 고가의 최댓값.
3. 장대양봉: (D 종가 − D 시가) ÷ D 시가 ≥ 5%.
4. 제외: D 또는 직전 250일 중 하루 종가 변동 ±30% 초과(수정주가 의심).
5. 중심값 M = (D 시가 + D 종가) ÷ 2. 같은 종목은 보유 중(아래 규칙 기준) 새 신호를 무시하지 않는다(사건 단위, 겹침 허용).

## 비교 (모두 D 종가 진입, 비용 매수 0.095% / 매도 0.275%)
- **MID (게시물 규칙):** D+1부터 매일 종가 < M이면 다음 날 시가에 매도. 끝까지 지키면 D+20 종가 매도. 다음 날 시가가 없으면 그날 종가.
- **H20 (손절 없음):** D+20 종가 매도.
- **H1 (바로 사서 다음 날 팜):** D+1 종가 매도.
- **R20 (무작위):** 같은 D일 같은 대상 300 중 무작위 1종목, D 종가 진입 → D+20 종가 매도 (시드 0~4 평균).
- **주장 ① 검정:** D+1 종가 ≥ M인 사건(지킴) vs < M(못 지킴). 각각 D+1 종가 진입 → D+21 종가 매도 수익(비용 포함) 평균.
- D+20(또는 D+21)까지 데이터가 없는 사건은 제외.

## 합격 기준 (모두 충족)
1. 사건 수 ≥ 100
2. MID 거래당 평균(비용 후) > 0, PF ≥ 1.2
3. MID 평균 ≥ R20 평균 + 1%p (신호+규칙이 무작위보다 나음)
4. MID 평균 ≥ H20 평균, 그리고 MID 하위 10% 분위 > H20 하위 10% 분위 (손절 규칙이 손실 꼬리를 줄이면서 평균을 깎지 않음)
5. 신호 연도별 MID 평균이 모두 > 0 (사건 20개 미만인 연도는 판정 제외)
6. 주장 ①: 지킴 평균 − 못 지킴 평균 ≥ +1%p

합격 → 분봉·자금 제약(동시 보유 3종목, 실제 계좌) 재검증 → 실전은 별도 승인. 불합격 → 기록하고 종료.

## 한계
- 일봉 근사(종가 체결, 장중 경로 무시), 이미 본 기간(2024-11~), 생존 편향, 사건 겹침(같은 시기 상승장에 몰릴 수 있음), 자금 제약 없음.
- 목표는 단타인데 이 규칙은 스윙(최대 20거래일)이다. 합격해도 봇의 별도 모드 여부는 사용자 결정.

## 1차 결과 (2026-10-12, `research/midpoint_explore.py`) — 불합격, 종료
- 신호 기간 20241127~20260907, 사건 3,240개(942종목). 거래당 수익은 비용 포함.

| | 건수 | 평균 | 중앙값 | 승률 | PF | 하위 10% |
|---|---|---|---|---|---|---|
| MID (중심값 손절, 최대 20일) | 3,240 | +2.45% | −5.64% | 27.4% | 1.39 | −13.71% |
| H20 (손절 없이 20일) | 3,240 | +3.37% | −2.45% | 45.2% | 1.37 | −26.93% |
| H1 (다음 날 종가 매도) | 3,240 | +0.32% | −0.50% | 43.6% | 1.12 | −7.85% |
| R20 (같은 날 무작위 종목 20일) | — | +2.39% | | | | |

- 연도별 MID/H20 평균: 2024(11건, 판정 제외) −5.08/+0.04, 2025 +3.28/+4.47, 2026 +1.77/+2.42.
- 주장 ①: D+1 종가가 중심값을 지킴 2,668건 +2.86% vs 못 지킴 572건 +1.45% (차이 +1.41%p). 두 그룹 모두 중앙값은 음수(−2.62/−3.19).
- 판정: ✅ 사건 수 / ✅ 평균·PF / ❌ 무작위 + 1%p(+2.45 vs +2.39) / ❌ H20보다 평균 낮음(꼬리는 −26.9 → −13.7로 줄었음) / ✅ 연도별 / ✅ 주장 ① → **불합격**.
- 해석:
  - 수익 +2.45%는 같은 날 아무 종목이나 20일 들고 있어도 나는 수익(+2.39%)과 같다. 2025~2026 상승장의 몫이고 신호·규칙의 우위가 아니다.
  - 중심값 손절은 큰 손실 꼬리를 절반으로 줄이지만, 71%가 중도 청산되고 승률 27%로 평균을 0.9%p 깎는다(5% 이상 장대양봉이면 중심값까지 이미 2.5% 이상 아래라 손절 한 번이 작지 않음).
  - 주장 ①은 방향은 맞다(지킴 > 못 지킴 +1.4%p). 다만 지킨 쪽 +2.86%도 무작위(+2.39%)와 큰 차이가 없고, 못 지킨 쪽도 평균은 양수라 "못 지키면 진 것"까지는 아니다.
  - "바로 사면 손해"도 평균으로는 재현되지 않았다(H1 +0.32%, PF 1.12). 장중 되밀림 손해는 분봉 탐색(`pullback_plan.md`) 쪽 결과다.
