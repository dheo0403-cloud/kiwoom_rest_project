# 상승 중 보유·꺾일 때 매도(청산 규칙) 검증 계획 (2026-10-26 고정, 결과 보기 전)

## 배경
- 10/26 장중 8건 중 본절스탑 2건(앤로보틱스 최고 +1.39%→0.00%, 레몬헬스케어 최고 +1.5%→+0.12%)이
  청산 후 30분 안에 매수가 대비 +1.6~2.6%까지 더 올랐다. 트레일링 스탑 1건(삼성E&A 최고 +1.68%→+0.67%)만 수익을 지켰다.
- 현재 규칙: 최고 +1.2% 도달 시 본절선(매수가 +0.25%), +1.5% 이상이면 트레일링(고점 −2.0% 또는 고점 − 2×ATR, 바닥 +0.25%).
  +1.2~1.5%에서 꺾이면 본절선까지 그대로 내려와 판다.
- 사용자 요청: 오르는 동안은 들고 있다가 떨어지기 시작할 때 파는 방식을 백테스트.

## 후보 (모두 `strategy_params.json` 범위의 파라미터만 변경)
| 이름 | 설정 | 의도 |
|---|---|---|
| base | 현재값 | 기준 |
| early_trail | `trailing_activation_pct=0.008`, `breakeven_trigger_pct=0.008`, `atr_trailing_stop_mult=1.0` | +0.8%부터 고점을 따라가며 고점 − 1×ATR 아래로 꺾이면 매도 (바닥 +0.25%) |
| hold_trail | `breakeven_trigger_pct=0.03` (limits.py 상한) | 본절 매도를 +3%까지 미루고 +1.5% 트레일링만 유지 (흔들려도 더 들고 있음) |

- 두 후보 모두 weekly_review_rules.md §4의 1회 변경 폭(비율 ±25%, ATR 배수 ±0.5)과 주 1개 규칙을 넘는다. 사용자 요청 연구라 그대로 돌리되, 합격해도 사이클 자동 반영이 아니라 사용자 결정(제안)으로 다룬다.

- 코드 전제: 샹들리에 스탑의 가동 조건이 `최고가 ≥ 매수가 × 1.015` 고정값이었다. 이를 `trailing_activation_pct`로 바꿨다(현재값 0.015라 실거래 동작은 같음). 이 변경이 없으면 early_trail의 +0.8~1.5% 구간에서 트레일링이 걸리지 않는다.

## 실험
- 공통: `backtest.py <code> --confirm-minutes 5` (실거래와 같은 신호 확인 매수), 기본 WFO(train 20 / test 5), 슬리피지·수수료·세금 포함.
- 종목: 086520, 042510, 396300, 011200, 006800, 010140 (10/21·10/22 백테스트와 같은 6종목).

## 합격 기준 (weekly_review_rules.md §5 + min_stop_plan.md, 하나라도 못 넘으면 현재값 유지)
1. 후보의 OOS 합계가 base보다 높은 종목이 6개 중 4개 이상.
2. 6종목 거래당 손익(비용 후) 평균이 base보다 **+0.05%p 이상** 높음.
3. 어느 종목도 OOS 합계가 base보다 5%p 넘게 나빠지지 않음.
4. 6종목 PF(합산 총이익/총손실)가 base보다 높음.
- 두 후보가 모두 합격하면 거래당 손익 평균이 더 높은 쪽을 고른다.
- 합격해도 장중 전략 전체가 손실이면 "손실 축소"로만 기록한다. 실거래 반영은 주간 검토(§4 주 1개)와 사용자 승인을 거친다.

## 편향
- 백테스트는 1분봉 단위라 청산은 봉 저가로 판정한다(보수적). 실거래는 틱 폴링이라 트레일링이 더 빨리 반응한다.
